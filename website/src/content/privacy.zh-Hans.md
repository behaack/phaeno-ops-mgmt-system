###### **公共网站分析**
在 [www.phaenobiotech.com](https://www.phaenobiotech.com) 上，我们使用 Vercel Web Analytics 来了解网站总流量并改进我们的内容。该服务记录页面浏览量，并可能处理事件时间戳、页面路径、引用网站、大致地理区域、设备类型、操作系统和浏览器。我们在发送分析事件之前删除查询字符串和页面片段，并且我们不会将表单中输入的信息发送到 Web Analytics。

Vercel Web Analytics 不使用分析 Cookie 或创建跨网站或跨天跟踪访问者的个人资料。它使用从 24 小时后重置的请求数据派生的哈希值来估计每日唯一访问者。 Phaeno 接收与访问者姓名、电子邮件地址或存储的 IP 地址无关的汇总报告。 Vercel 作为我们的网站托管和分析服务提供商处理此信息。有关更多信息，请参阅 [Vercel 的 Web Analytics 隐私文档](https://vercel.com/docs/analytics/privacy-policy)。
