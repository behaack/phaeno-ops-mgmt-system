# How to create and approve a lab protocol

Use this guide to author a complete library protocol in **Lab settings → Protocols**.
Work in the Phaeno organization with protocol-management access. The approved
protocol is a configuration reference; it does not record performed laboratory work.

## 1. Start a protocol or a revision

Choose **New protocol**, enter its name and description, then continue to the
definition editor. For an existing protocol, open **Actions** and edit its current
Draft or create a new version. Keep a clear purpose and scientific scope in the
description. Changes to an approved protocol belong in a new Draft; they do not
rewrite an earlier approved revision or a run pinned to it.

## 2. Write the complete procedure

![Top of the protocol editor showing the ordered instruction outline, selected instruction fields and Configuration preview button.](/docs/phaeno/screenshots/protocol-editor-20261015.jpg "Top of a demonstration editor; this example is not a scientifically qualified SOP.")

1. **Ordered outline:** select an instruction to work on it. Use **Add step**
   for another instruction.
   Drag its handle, or choose **Move up / Move down** in
   its Actions menu, to put the procedure in execution order.
2. **Selected instruction:** write the instruction directly and configure its
   required confirmations, recording fields, resources, QC criteria and handoffs.
   Each occurrence belongs to this protocol; a separate Lab-step approval is not
   required.
3. **Configuration preview:** try the recording controls with fictional examples.
   The preview does not create laboratory records. Separately, expand **Review
   overview and bench instructions** below the editor to inspect the complete
   procedure and its recording requirements before saving.

Use **Insert from an approved procedure** when reviewed source instructions can
be reused. The copied instructions become independent content in this Draft and
retain their source attribution. Review them in the receiving protocol's context;
later edits to the source do not update this copy.

Add optional illustrations where they clarify an instruction. Supply meaningful
alternative text and any necessary caption. Use the supported static image types
and review the uploaded image before approval. Do not place confidential data in
a reusable procedure illustration.

## 3. Save and review the Draft

Choose **Save initial draft** for initial setup, **Create protocol draft** for a
successor, or **Save draft** when editing a saved Draft. Return to Protocols and
open its name or pending-Draft link.
Check the exact revision, ordered content and recording requirements. In the
presentation toolbar, choose **Process overview** or **Bench instructions**.
Choose **Letter** or **A4** before using the print commands in **Actions**.
Where offered, **Preview recording controls** is a fictional preview and creates
no laboratory execution evidence.

If another user changes the Draft, reload and reconcile the saved content before
trying again. Saving does not approve the protocol or make it ready for new runs.

## 4. Approve the complete revision

From the protocol's **Actions**, choose **Review and approve**. Review the complete
revision, including copied content, illustrations and required capture fields.
Independent approval is required. When permitted, a platform administrator may
use the explicit administrator-override action and record the reason; ordinary
authors cannot bypass independent review.

After approval, confirm the **Approved** revision and approval evidence. Library
workflows select exact approved protocol revisions. Existing workflows and
performed work keep their pins when a later revision is approved. To prevent
future use, use the controlled retirement flow and review its dependency impact.

See [Service workflows, protocol control, and execution](/docs/phaeno/lab-protocol-execution)
for copying, illustration limits, execution and retirement rules, and
[Laboratory operations](/docs/phaeno/lab-operations) for the surrounding workflow.
