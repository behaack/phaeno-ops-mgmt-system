# Partner data assembly

Order Ops owns the Commercial Data Assembly order, quote, approval, cancellation, and accounting source record. Lab Ops owns input validation, processing milestones, quality review, and immutable output release. Inputs and outputs are manufacturing records; they are not source samples for Data Provisioning.

Find the Commercial order in **Order operations** > **Orders** with order type **Data Assembly**. Open **Lab operations** > **Data assembly** to validate the submitted input and perform the manufacturing workflow. When Lab accepts the input, Commercial staff issue the quote from the linked order; manufacturing continues after Partner acceptance.

## Validate the submission

Confirm the active Partner, project reference, purchase-order requirement, selected active assembly profile, required metadata, and uploaded input revision. Validate file type, size, completeness, malware-scan state, and every profile-specific requirement.

When the submission cannot pass input validation, Lab staff place the manufacturing record on hold and document the issue. Commercial staff use the linked order to request a targeted Customer correction or reject work that is unsafe, unsupported, or outside the offered profile. A correction creates a new input revision; it must not rewrite the revision that was reviewed previously.

## Quote and accept the job

Prepare the per-job quote from the current assembly offering and preserve its profile, price, currency, and expiration snapshot. Issuing the POMS quote makes it available to the Partner immediately. Acceptance records the immutable Commercial commitment and queues the work.

## Process and review

Record processing milestones against the accepted input revision and selected profile. Internal implementation details and intermediate files remain internal. When processing is complete, perform the configured quality review and document any hold or required correction.

## Approve an output release

An output release is immutable and identifies:

- the exact source input revision;
- the assembly profile and version;
- the output manifest and included files;
- checksums, scan state, and generation time; and
- the quality-review and approval facts.

Approve a new release rather than replacing a prior release. POMS creates the accounting source record, then applies the Partner’s assembly-credit gate. Credit-approved work can be released under Net 30; work without approved credit remains on payment hold because manual payment confirmation is not yet implemented.
