# Billing, payment, and release gates

POMS owns immutable quotes, commercial source records, credit decisions, and file-release gates. QuickBooks Online integration is deferred; Phaeno Finance uses the journal-entry source report for manual accounting work outside POMS.

## Understand document timing

- Customer lab and Partner assembly quotes become available immediately when Phaeno issues them in POMS.
- Customer lab completion and Partner assembly output approval create a final accounting source record.
- Each Partner reagent shipment creates its own accounting source record, so partial shipments appear separately.

The source report includes stable IDs, operational references, currency, gross amount, and the POMS balance. Finance chooses accounts, tax treatment, posting dates, and any later adjustment in the accounting system. Downloading a report does not mark entries as posted.

## Apply Customer release gates

A Customer result may be published only when the specific sample is scientifically ready, the release definition is approved, every file is present and checksummed, malware scanning passed, and the required commercial source record exists.

For a Customer with approved credit, Phaeno may release a ready sample result under the configured Net 30 terms without waiting for payment. Without approved credit, no job result is downloadable. Payment confirmation and manual release are not implemented; do not clear the hold through an order-status change.

## Apply Partner assembly release gates

An approved output release must reference the accepted input revision and active assembly profile. Its accounting source record is created at output approval. A Partner with approved assembly credit may receive the output under its terms; otherwise the files remain on payment hold until a separately approved payment-confirmation workflow exists.

## Diagnose a blocked release

Review scientific readiness, output approval, file scan and checksum state, accounting-source readiness, credit approval, and publication independently. Show the tenant that work is ready but held when appropriate, without exposing the files. Never bypass a failed gate by attaching a file manually or changing an unrelated workflow status.
