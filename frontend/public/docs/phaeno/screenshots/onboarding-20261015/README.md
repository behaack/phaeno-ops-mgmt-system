# Customer onboarding illustrations

Fifteen captures were refreshed October 22, 2026, from actual Company, Department,
request, invitation-review and billing components. Every person, account, address,
permission and tax choice is fictional. No invitation/email, hosted record or
provider write was needed. These images do not establish live acceptance or
approved commercial facts.

Stable asset names retain the original October 15 identity. Current provenance,
source dependencies, crops, asset hashes and review are recorded in
`frontend/ui-gallery/documentation-captures.json`. Display-only coordinates live
in `documentation-capture-metadata.json`; explanations and alt/captions live in
`how-to-onboard-customer.mdx`. Focused views may omit surrounding navigation.

Run the independent gallery and `pnpm docs:captures:refresh`, inspect every frame
and marker, then `pnpm docs:captures:review`. The read-only capture check detects
stale source dependencies, missing images and invalid annotations. Do not alter
old pixels to simulate the current UI.
