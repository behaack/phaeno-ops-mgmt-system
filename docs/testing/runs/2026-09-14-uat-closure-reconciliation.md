## Rules for ending the loop

1. No more broad suite runs unless a diagnosed change or a specifically missing acceptance assertion requires them.
2. Reuse saved evidence and immutable records. Do not rerun completed import, allocation, dispatch, receipt, accession or publication commands to make a report easier.
3. Before each connected session, name the exact case steps being closed and their evidence. After it, update this document and the run ledger with closed steps, defects and blockers.
4. Do not invent new requirements such as all file formats when the script requests one approved format. Conversely, do not omit explicit original-PDF, recipient receipt, physical or role variants.
5. When a package cannot proceed, stop that branch at its documented dependency and continue an independent R case. Ask the owner only for a concrete unavailable input or true product decision, not technical preferences.
6. Final exit is 81 case dispositions on the chosen baseline: Pass or an explicit accepted exclusion/blocker disposition. A waiver must be deliberate and scoped; no waiver is requested or assumed here.
