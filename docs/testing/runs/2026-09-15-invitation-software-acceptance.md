## Isolation and cleanup

Each new PostgreSQL test requires a known loopback source (`phaeno_ops` or `phaeno_ops_lab06_uat`), creates only its own `pseq_invite_test_<random>` database and migrates that disposable database. This allows actual acceptance commits without touching the original UAT records. Each database is dropped in cleanup; final inspection found none remaining. No shared schema was migrated.

An ephemeral data-protection provider protects the test delivery payload. Raw invitation URLs/tokens and provider authorization values stay inside the test process; none is written to the report or retained fixture evidence. Synthetic verification data is not a real credential/MFA record. The sender's HTTP handler only accepts `email.example.test` and never contacts a provider. No actual message, membership change outside the disposable databases, Git mutation, push or deployment was performed.
