Their case IDs in these reports are historical labels, not current test instructions or acceptance criteria.

Use the current product workflows, implementation, audience guides, and living backend, frontend, and E2E test plans to scope a new acceptance run. Keep simulated, connected, provider, physical, scientific, and business sign-off evidence distinct.
