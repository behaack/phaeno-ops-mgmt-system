# HP-16 — Included Assembly inputs through Partner delivery

**People:** Partner administrator; Assembly operations and scientific reviewers; authorized Partner member.

**Ready before starting:** Shipped Kit/case from HP-15, approved Assembly credit on the original purchase, valid submission window, known-good allowed input files/metadata and prepared scientific output process.

| Step | Person and action | Expected result |
| --- | --- | --- |
| 1 | Partner administrator: open PSeq Kit orders → the order → Included assembly cases → Prepare inputs. | The intended Kit, lot, deadline and frozen profile appear. |
| 2 | Enter the Partner reference and required metadata. Upload the prepared files and wait for all managed uploads and clean scans. | Saved inputs meet the displayed file and profile requirements. |
| 3 | Save draft, reopen it and review the files and metadata. | The same case retains its preparation progress. |
| 4 | Affirm the prohibited-data statement and Submit for intake validation. | The submitted input revision is frozen and awaits review. |
| 5 | Assembly staff: open the submitted case, inspect its valid inputs and accept intake. | Included work enters the processing queue linked to the original purchase. |
| 6 | Perform the approved upstream processing and record its progress in the case; prepare and register the complete output package for review. | Output files and manifest identify the accepted input revision and profile. |
| 7 | Authorized scientific/release staff: complete output review and the supported release action with the original approved Assembly credit. | The approved output becomes available under the original Kit's commercial context. |
| 8 | Partner member: open the case and Download package. Open the saved ZIP and inspect its manifest/files. | The complete approved output downloads successfully. |
| 9 | Review View retained package receipt and Print / save PDF; return to the original Kit order. | Receipt records package facts, and the single included case/order shows its completed outcome. |

**Done:** Record input revision, output release and completed-download receipt. No second Assembly purchase or quote is part of this included-case journey.
