# HP-10 — Prepare libraries in a tray

**Person:** Laboratory operator authorized for the approved protocol.

**Ready before starting:** Accepted source tubes from HP-09, compatible active workflow/tray from HP-05, confirmed tube-use instructions and approved materials/equipment. The test SOP selects one source tube per sample and supplies successful QC observations. SAMPLE-B's second tube remains stored as reserve material.

| Step | Action | Expected result |
| --- | --- | --- |
| 1 | Open Lab operations → Library prep and create a preparation batch using the approved tray format and workflow. | The batch opens with its generated identifier and named positions. |
| 2 | Scan each SOP-selected accepted tube into its intended tray position. Review tube, sample and Job identities. | The tray shows the intended source tubes and positions. |
| 3 | Choose Start preparation and confirm the prepared tray. | Membership locks and the first protocol stage is available. |
| 4 | Perform each SOP step in order. Enter its required observations and confirmations, explicitly review the covered tubes, and record the used material lots/equipment through the stage actions. | Saved evidence is attached to the correct steps and tubes. |
| 5 | Record the approved successful QC observations and Pass decisions. Complete intermediate stages in order, keeping the final stage open for its output confirmation. | Completed stages show their evidence and the next stage is clear. |
| 6 | At the SOP's output step, choose Create library output for each processed tube. Record actual quantity, unit and storage; label the output and scan Confirm output identity. | Each output has confirmed identity and preserved source lineage. |
| 7 | Complete the final stage after all required evidence and output identities are saved. | Libraries are created using the existing recorded QC evidence. |
| 8 | Complete the preparation batch and review its libraries. | The batch is complete and its QC-passed libraries are eligible for sequencing. |

**Done:** Record preparation batch and library barcodes. Continue [HP-11](11-sequencing.md) with these libraries.
