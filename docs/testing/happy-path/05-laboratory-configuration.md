# HP-05 — Prepare an approved laboratory workflow

**People:** Protocol administrator/author; a different protocol administrator/approver.

**Ready before starting:** Laboratory-owner-approved test SOP and scientific values, active commercial service, prepared valid material lots/equipment and a tray layout. Use the designated test configuration.

| Step | Person and action | Expected result |
| --- | --- | --- |
| 1 | Author: open Lab operations → Lab configurations → Protocols and start a protocol draft. | The structured definition builder opens. |
| 2 | Enter the test protocol name and SOP steps. Select Use this version for preparation batches; define the approved capture, QC, resource and tube/barcode requirements. | The draft describes the intended bench sequence and evidence. |
| 3 | Choose Create protocol draft and reopen the version. | The complete definition is saved as a draft. |
| 4 | Independent approver: open the version, choose Review and approve, inspect it and attest approval. | The exact version is approved and locked. |
| 5 | Author: open Workflows, create the test service workflow and Add version. Add the approved protocol stages in the SOP order and save. | The draft workflow links the intended service and protocol versions. |
| 6 | Independent approver: review and approve that workflow version, then use Promote to production for the test workflow. | This version becomes the active selection for laboratory work in this environment. |
| 7 | Author: open Tray formats → New tray format. Enter the approved layout, review the position preview and save. | The active format shows the expected positions and capacity. |
| 8 | Review the prepared materials/equipment and the saved workflow and tray from their lists. | Operators can identify the required current resources and approved configuration. |

**Done:** Record protocol/version, workflow/version, tray and resource references. Prepare HP-06 only after these are ready. “Promote to production” here activates a scientific workflow version in the selected environment.
